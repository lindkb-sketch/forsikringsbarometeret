# Report-first production contract (nine insurers)

The original official interim/quarterly report is the primary source for
every available KPI. Official annual-report Q4 derivation is permitted only
under the issuer-specific already-approved source reconciliation rules.
Frende Holding's official digital report is a report, not a press release.
A company's official filing distributed through Nasdaq/NewsWeb is still
the company's original report; delivery and source identity are distinct.

Alm. Brand's Q3 baseline is promoted from an actual re-downloaded,
fingerprint-checked PDF using the rolling report parser, including all nine
quarter and cumulative metrics and original page evidence. Growth remains
rounded to the existing display precision (1.6%, derived from PDF comparatives).
Existing values may not be changed by the migration. The old announcement
and presentation importers cannot downgrade the promoted baseline.

Future Alm. Brand periods use issuer archive and results-announcement links,
with a fallback to the actual Nasdaq Nordic news RSS and a period/issuer-bound
official attachment. Unknown layouts, invalid source URLs, wrong periods,
or ambiguous reports fail closed. Presentation evidence is supplemental:
absence or unavailable layout is a warning; a confirmed conflicting
solvency ratio blocks import. A diagnostic with unresolved presentation
slots must not be read as a primary-source KPI gap or full reconciliation.

The production gate checks all nine actual published comparison records,
quarter and HIÅ report provenance, and the audited projection before
publication. New-period receipts must still be observed in a scheduled run
after an actual report is released. An existing snapshot or test fixture
is not proof that future unattended ingestion has occurred.
